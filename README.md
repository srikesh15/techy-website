# 🚀 Techy Website

A modern, responsive company website built with **React** and **Vite**. This project is being developed to strengthen my React skills by building a real-world software company website from scratch.

## 🌐 Overview

**Techy** is a fictional software company that offers digital solutions such as web development, mobile app development, cloud services, and UI/UX design. The website showcases the company's services, projects, and contact information through a clean and modern user interface.

## ✨ Features

* Responsive navigation bar
* Hero section
* Services section
* Reusable React components
* Modern and clean UI
* Responsive design
* Smooth user experience

## 🛠️ Tech Stack

* React
* Vite
* JavaScript (ES6+)
* HTML5
* CSS3

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/<your-username>/techy-website.git
```

Navigate to the project folder:

```bash
cd techy-website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:5173
```
